## Что умеет

- `look` — домен -> IP, IP -> PTR
- `find` — поиск поддоменов по словарю (с рекурсией)
- `find path` — скан путей/директорий по словарю
- `google links` — генерация Google dork ссылок
- `api scan` — проверка endpoint-ов из OpenAPI

## Глобальный флаг

- `--lang auto|ru|en` — язык сообщений CLI
