# Google Hacking

Команда `google links` генерирует готовые Google dork ссылки для домена.

## Запуск

```bash
cerber google links qatoria.ru
```

или с режимами:

```bash
cerber google links qatoria.ru --mode 1,5,12
```

## Режимы

- `all` — все доступные шаблоны dork-запросов
- `1,2,3...` — конкретные шаблоны через запятую

## Применение

- Поиск открытых документов
- Поиск административных интерфейсов в индексе
- Поиск утечек по домену через indexed-страницы
